Initial Evaluation Coding — Capture What You Deliver

Initial evaluations are often your highest-effort visits. If every intake is billed as a flat 90792, the claim may under-represent the real time, medical complexity, and psychotherapy work actually delivered.

1) The Problem

90792 is a flat code (~$150). It pays about the same for a 45-min or 90-min intake, simple or complex. Billing it on every intake likely under-codes your most valuable visit.

2) Better / More Accurate Options

Instead of flat 90792 Use when it's the truer code Notes
99204 / 99205 (new patient E/M) High medical decision-making intake 99205 = high complexity; often reimburses more than 90792
99205 + 90838 Also performed real psychotherapy (≥53 min) Captures BOTH eval and therapy time; count times separately
+ 90785 Interactive complexity (collateral informants, difficult disclosure) Legit add-on
+ 99417 (commercial) / G2212 (Medicare) Intake genuinely ran long (time-based) Attaches to E/M code, requires documented start/stop times
+ 95 modifier Telehealth POS 10/02

3) Quick Decision Tree

Standard, med-focused intake → 90792
Complex + high MDM + ran long → 99204/99205 (± prolonged)
Complex + real psychotherapy (≥53 min) → 99205 + 90838
Interactive complexity present? → add 90785
Telehealth? → add 95 modifier + correct POS

5) THE ONE QUESTION FOR YOUR BILLER

“We currently bill 90792 on every new-patient intake. Given the time and complexity of a psychiatric evaluation, would 99204/99205 (± 90838, ± 90785) reimburse higher with our top payers? Please pull our fee schedule and give a written answer with the highest-paying ACCURATE option for a complex intake.”

6) Why Claims Reject When Adding Codes

  • ☐ Add-on billed without a valid primary code
  • ☐ Missing modifier (+95, etc.)
  • ☐ Time not documented (start/stop times missing)
  • ☐ Same-day 90792 + E/M conflict
